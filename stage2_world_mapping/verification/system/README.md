# Stage 2 V1 System Verification (Claude-owned)

Run from `stage2_world_mapping/`:

```sh
python3 verification/system/run_system_tests.py            # full (about 2.5 min)
python3 verification/system/run_system_tests.py --quick    # smaller real subset
```

Requirements:
- Icarus Verilog (`-g2012`) and Verilator (lint).
- In-tree numeric RTL and fixed-point model; the runner defaults to `../rtl` and `../../model` (compatibility copies remain under `codex/`).
- The compact selected Sept. 22 fixture under `reference/real_traffic/` for the real-traffic scenario. Full decoded caches and raw recordings are local-only.

## What every test checks

Each run simulates **two complete DUTs** on the same stimulus: D2 (`MERGE_EN=0`) and E-lite (`MERGE_EN=1`). Each must pass:

1. Every mapped event, in issue order, has the golden world address **and** the golden carried `(x, y)` (metadata alignment across the 53-enabled-edge lanes). Golden = fixed-point `FixedT32Mapper` + `ray_q15_to_world_address`.
2. Exact counters: words, events accepted / dropped / issued / mapped, **issue cycles = Σ ceil(n/2)**, RMW records (E-lite = Python consecutive-merge reference; D2 = events), merged records, events applied, saturation loss.
3. Final world memory = golden (all 2,048 tile words).
4. **D2 and E-lite final memories bit-identical** (2,048/2,048 words).
5. Event conservation: Σ memory (ON+OFF) + saturation loss = events accepted, with pending = 0 and dropped = 0 for valid events.
