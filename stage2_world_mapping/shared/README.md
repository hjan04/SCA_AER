# Shared workspace

This area holds deliberately managed material intended for both independent
workspaces to read. Neither agent should casually modify shared files during
independent exploration.

- `specs/`: stable Stage 2 assumptions and specifications, once established.
- `interfaces/`: future shared interfaces between models, RTL, and Model2.
- `experiment_contracts/`: common inputs, outputs, metrics, and experiment
  formats for later result comparisons.

No competition specifications are asserted here yet.
